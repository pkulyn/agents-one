# Known issues and release limitations

Agents One is MIT-licensed Alpha source. Public source availability does not certify an installer or every Runtime integration.

| ID           | Current limitation                                                                                                                                         | Required before closing                                                                                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| AO-KNOWN-001 | There is no accepted public installer Release.                                                                                                             | Qualify the final package on a clean Windows user environment, including install, upgrade, uninstall and rollback. |
| AO-KNOWN-002 | Windows Alpha builds are unsigned; SmartScreen may warn and automatic updates are disabled.                                                                | Verify signing, publisher identity, update metadata and rollback before enabling updates.                          |
| AO-KNOWN-003 | macOS and Linux are not supported public binary targets.                                                                                                   | Complete independent platform packaging, installation and Runtime checks before publishing assets.                 |
| AO-KNOWN-004 | Doubao, ChatGPT and Grok browser adapters are default-off experiments; enabled use sends selected content to the provider and may affect account standing. | Establish an acceptable provider authorization basis and verify privacy, login isolation and the kill switch.      |
| AO-KNOWN-005 | Some POSIX integration tests and strict nested YAML path cases remain outside the Windows verification scope.                                              | Run the relevant platform cases and resolve unsupported YAML semantics.                                            |
| AO-KNOWN-006 | Linux secret protection may fall back to restricted files when no secure OS backend is available; non-Windows Connector secrets rely on file permissions.  | Verify platform keyring integration before qualifying those platforms.                                             |
| AO-KNOWN-007 | Renderer bundle sizes have no enforced regression budget.                                                                                                  | Establish a reviewed size budget without changing Runtime behavior.                                                |
| AO-KNOWN-008 | Remote Hermes multi-turn recall and restart continuation remain experimental.                                                                              | Verify the deployed Connector's native session mapping, restart recovery and conversation isolation.               |
| AO-KNOWN-009 | Packaged cancellation, scheduling, restore failure and compatibility paths need further acceptance evidence.                                               | Verify the affected paths against the final package without replacing evidence with synthetic fixtures.            |
| AO-KNOWN-010 | Local OpenCode long-task and post-cancel recall fixes passed adapter checks, but are not yet qualified in a replacement public installer.                  | Verify the final packaged UI uses the repaired adapter and retains the same native conversation.                   |

Never put credentials or private logs in a public issue. Report vulnerabilities through [SECURITY.md](SECURITY.md).

# Agents One 品牌与启动动效规范

## 品牌字标

- 产品名固定写作 `Agents One`；导航和启动页允许使用全大写视觉字标。
- 彩虹 dawn ring 直接替代单词 `ONE` 中的字母 `O`，不得再放进白色圆角底板。
- 独立 dawn ring 仅用于窗口图标、关于页、favicon 等必须使用单体标记的场景。
- 折叠侧栏保留现有彩色圆角方形标记，并在 hover/focus 时切换为展开图标。

## Design System

- 常驻界面：浅色主题字标文字 `#171A21`；深色主题字标文字 `#F5F7FA`。两种版本只切换字母纯色，Dawn Ring 保持同一品牌渐变。
- 启动舞台：深海军蓝 `#041426`，字标文字 `#F5F7FA`。
- Dawn ring：`#2C92F5 → #7064E8 → #D976AA → #FFC46A → #2C92F5`；渐变只用于品牌圆环和接触光，不用于文字。
- 字标字体：`Oxanium 700`。启动页与展开导航栏使用同一套几何字形，并固化为 SVG 矢量路径；运行时不加载外部字体，也不依赖系统字体回退。
- 间距：8px 基数；常驻界面不新增阴影和装饰底板。
- 动效：机器手与人手在 1.1 秒内使用 `cubic-bezier(0.45, 0, 0.2, 1)` 靠近并接触；约 1.06 秒在指尖出现接触光，约 1.20 秒字标从接触点显现。启动页最低展示 2.9 秒，字标可见约 1.7 秒，其中约 0.7 秒入场、约 1 秒稳定展示。
- 可访问性：遵循 `prefers-reduced-motion`；减少动态效果时直接展示静态双手画面与最终字标。

## 启动动画构图

- 使用用户提供的机器手/人手照片作为唯一主视觉，不叠加无关粒子或通用科技口号。
- 将同一照片沿指尖接触区域分为机器手层和人手层，两层从相反方向缓慢靠近，终帧无错位。
- 两层终点采用对称位移，使原图留白真正闭合；接触锚点统一为画面 `50% / 44%`，接触光和字标均从同一点触发。
- 接触点只出现一次短促十字光晕；完整字标从该点缩放、去模糊，并在入场完成后稳定显示约 1 秒。
- 加载状态与远程连接逃生按钮继续保持可读，并位于动画主视觉之外。

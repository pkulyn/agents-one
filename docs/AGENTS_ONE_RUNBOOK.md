# Agents One 使用与验收手册

## 日常使用

1. 在“设置 -> 智能体运行时”中维护 Hermes、OpenClaw、Codex、Claude Code 的连接与健康状态。Runtime 是连接能力；显示名称、图标和颜色属于用户可见的智能体身份。
2. 普通事项在“对话”中处理。上传的附件或所选项目目录只会随当前对话/任务发送，不会自动授权给其他智能体。
3. 复杂工程在“项目”中创建：填写目标、选择项目目录和关联对话，再在“项目协作组”中指定项目经理、实施、测试、复核和验收者。
4. 添加项目任务时写清需求和验收标准。前置任务未验收前，下游任务会显示“已阻塞”；验收通过后自动变为“待分配”。
5. 选择执行智能体后，仍需手动点击“分配”和“派发”。实现型任务只允许 Codex 或 Claude Code，且应在受管 Git worktree 中执行。
6. 派发前可点击“生成上下文”。上下文包只包含项目目标、上游摘要、工作目录和产物引用；不会复制产物正文、密钥或完整无关对话。
7. 运行中的日志、产物、取消与验收在“任务中心”查看；项目任务卡的“在任务中心查看”可快速跳转。

## 计划任务

- “任务中心 -> 计划任务”分为两类：**Agents One 计划任务** 与 **Hermes Cron 计划任务**。
- Agents One 计划任务由桌面端在应用运行时触发，可选 `skip`、`queue`、`replace` 并发策略。关闭应用后不会补跑错过的周期。
- Hermes Cron 保持 NAS 端原有语义，仍由远端 Hermes 管理。不要将两类规则复制成相同周期，以免重复执行。

## 推荐协作验收

创建一个小型测试项目，按以下顺序走完一次闭环：

1. 指定 Hermes 或 OpenClaw 为项目经理，Codex 为实施，OpenClaw 或 Hermes 为测试/复核，人工为验收。
2. 项目经理只生成受控计划。确认草案后才创建子任务。
3. 将一个分析任务验收通过，确认依赖它的实现任务从“已阻塞”变为“待分配”。
4. 为实现任务生成上下文，分配 Codex 并派发；检查 worktree、运行日志、diff 或测试报告。
5. 复核任务产物后，在项目页写入验收记录，选择“通过”或“退回”。

## 执行过程阅读

- 对话中的执行过程是面向用户的摘要，不是 CLI 原始日志。
- “思考”默认折叠，只保留最近的完整摘要；短半句和重复 snapshot 会被合并或隐藏。
- 工具调用按 List Files、Read File、Write File、Terminal、Search 等分组展示。空参数调用和 started/completed 这类无决策价值事件默认不显示。
- 普通大模型答复不是产物。只有文档、代码、diff、测试报告、链接或远程 artifact 才作为产物展示。
- 如需排查底层 Runtime 行为，再进入诊断日志或 Task Center 原始输出；日常验收优先看对话中的摘要、工具结果和最终答复。

## 故障定位

| 现象 | 首先检查 |
| --- | --- |
| 远程 Runtime 不可用 | 运行时“探测”结果、Dashboard/API/WebSocket 状态、证书错误分类 |
| OpenClaw 任务超时 | Bridge 健康、任务状态轮询与取消接口；不要在 UI 中暴露 Bearer Token |
| Codex/Claude Code 不能实现 | CLI 登录状态、目标目录是否为 Git 仓库、工作目录权限、worktree 路径 |
| 项目下游一直阻塞 | 前置任务是否已由人工验收为“已验收”，而不只是 Runtime 成功结束 |
| 计划任务未执行 | Agents One 计划任务要求桌面应用运行；Hermes Cron 要检查远端 Dashboard/Cron |

## 数据与安全边界

- 本地数据位于 Hermes 兼容数据目录的 `desktop/` 下；品牌升级不会删除旧会话、任务或项目记录。
- Renderer 不保存 Runtime 密钥。事件、错误文本和上下文摘要会经过脱敏和长度限制。
- 不自动路由、不自动合并、不自动提交代码、不自动执行高风险系统操作。
- Windows 普通用户可运行开发版和解包产物；本机构建关闭可执行文件资源编辑/签名，以避开企业设备的符号链接权限限制。对外发布时应在有代码签名权限的 CI 环境重新启用签名。

## 发布结论

截至评估日，项目未取得豆包、ChatGPT/OpenAI 或 Grok/xAI 对桌面应用自动化访问其消费者网页、提取回复或代用户操作账号的书面许可，也没有可供本项目直接依赖的正式允许结论。因此三个内置 Provider 均不得在公开构建中默认启用。

通用 Web Agent 框架和 Provider 适配器可以保留在源码中，供本地研究与兼容性测试使用；运行前必须同时满足本地实验环境开关和用户风险确认。任何 Provider 只有在维护者保存了可审计的书面授权或正式合规结论，并重新完成本记录与回归验收后，才能调整公开发布策略。

## 工程控制

- 默认关闭：未设置 `AGENTS_ONE_ENABLE_EXPERIMENTAL_WEB_AGENTS=1` 时，登录窗口、健康探测、普通任务和计划任务均不得访问 Provider。
- 双重启用：本地实验开关只让功能“可选择”；用户仍须在设置页阅读第三方数据流、账号受限和封禁风险并明确确认。
- 一键停用：设置页停用会取消活动网页任务并销毁 Provider 窗口；`AGENTS_ONE_DISABLE_WEB_AGENTS=1` 可覆盖已保存的本地选择。
- 最小状态：启用记录仅包含布尔值和确认时间，不包含 Cookie、Token、账号、提示词或附件信息。
- 无远端采集：当前版本不连接远端 kill-switch 或策略遥测服务。本机紧急开关不发送任何凭据或账号数据。
- 可退出：用户在功能关闭时仍可删除 Runtime，并可清除指定 Provider/Profile 的独立 Chromium 存储和缓存。

## 重新评估触发条件

出现以下任一情况时，本记录失效，必须在发布或重新启用前复核：

1. Provider 条款、robots/自动化政策、登录或反滥用规则发生变化；
2. 取得书面授权、合作协议或正式法律意见；
3. 自动化范围扩展到新的域名、账号数据、下载类型或身份提供方；
4. 引入远端策略、遥测或 kill-switch；
5. 新增网页 Provider。

复核时必须记录条款版本、评估日期、证据链接、允许依据、负责人和逐 Provider 发布决定；“未发现禁止”不得替代明确允许依据。

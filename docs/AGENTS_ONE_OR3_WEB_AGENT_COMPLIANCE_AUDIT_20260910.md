## 实现边界

策略状态保存在现有桌面配置的 `experimentalWebAgents` 键中，只记录 `enabled` 和 `acknowledgedAt`。Cookie、Token、账号标识、提示词和附件不进入该记录，也不通过新增 IPC 返回。环境开关优先级如下：

1. `AGENTS_ONE_DISABLE_WEB_AGENTS=1`：强制关闭；
2. 未设置 `AGENTS_ONE_ENABLE_EXPERIMENTAL_WEB_AGENTS=1`：公开默认关闭；
3. 本地实验可用但用户未确认：关闭；
4. 本地实验可用且用户已确认：允许执行。

禁用策略不阻止删除 Runtime 或清除对应隔离分区的登录数据，确保用户随时可以退出和清理。已有 Web Runtime 配置继续可管理，但不能因历史配置、探测或调度而绕过总开关。

## 合规判断

2026-09-10 核对 OpenAI、xAI 与豆包现行官方条款后，没有找到本项目自动化消费者网页所需的明确允许依据，也没有项目持有的书面许可。工程决策不是推断“默认允许”，而是让全部 Provider 保持公开禁用。条款变化、取得授权、新增 Provider、扩展域名/数据范围或引入远端策略时必须重新评估。
